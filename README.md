# 🚀 DevPilot – AI-Powered GitHub Repository Assistant

> Connect your GitHub repositories, index your codebase, and interact with your code using AI-powered conversations.

## 📖 About DevPilot

DevPilot is an AI-powered GitHub Repository Assistant designed to help developers understand and interact with their codebases more efficiently.

Users can securely connect their GitHub accounts, access their repositories, index repository source code, and ask AI-powered questions about their projects.

DevPilot uses semantic search and vector embeddings to retrieve relevant code context before generating intelligent responses. This allows the AI to provide more accurate and context-aware answers about a repository.

The platform combines GitHub OAuth authentication, Spring Boot, Next.js, Google Gemini AI, PostgreSQL, and PGVector to create an intelligent developer experience.

---

## 📌 Features

- 🔐 Secure authentication using GitHub OAuth2
- 👤 Fetch authenticated GitHub user information
- 📂 Connect and access GitHub repositories
- 🤖 AI-powered chat using Google Gemini
- 🧠 Repository code indexing and intelligent context retrieval
- 🔎 Semantic search using vector embeddings
- 📊 PostgreSQL database integration
- 🧩 PGVector for storing and searching embeddings
- 🔒 Secure session-based authentication
- 🌐 Cross-origin support for frontend and backend deployment
- ☁️ Cloud deployment support using Vercel and Render

---

## ⚙️ How DevPilot Works

1. The user logs in using GitHub OAuth.
2. DevPilot retrieves the user's GitHub repositories.
3. The user selects a repository.
4. The repository is indexed.
5. Source files are processed and divided into smaller chunks.
6. Vector embeddings are generated for the code.
7. Embeddings are stored in PostgreSQL using PGVector.
8. The user asks a question about the repository.
9. DevPilot searches for relevant code context.
10. The relevant context is sent to Gemini AI.
11. Gemini generates an intelligent, context-aware response.
